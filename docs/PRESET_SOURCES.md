# 프리셋 규격 출처 기록

확인일: 2026-07-22 (Asia/Seoul)

이 문서는 프리셋 Registry에 입력한 규격과 제품 해석의 근거다. 링크를 실제로 열어 확인한 내용과 프로젝트 seed에서만 정한 관행 값을 구분한다. `lastVerifiedAt`은 페이지가 열렸다는 뜻이지 이후 규격 변경이 없음을 보장하지 않는다.

## 1. 한국 온라인 여권사진

- 기관: 대한민국 외교부 여권과
- 출처 종류: `official`
- 출처 1: [온라인용 사진파일 안내](https://www.passport.go.kr/home/kor/contents.do?menuPos=12)
- 출처 2: [온라인 여권 사진 검증](https://www.passport.go.kr/home/kor/onlinePhotoVerify/index.do?menuPos=33)
- 확인일: 2026-07-22
- 재검증: 출시 전 및 분기별 권장

확인한 규격과 제한:

- 온라인용 파일 안내는 JPG/JPEG, 500KB 이하를 제시한다.
- 413×531px를 권장하고 업로드 허용 범위를 가로 395~431px, 세로 507~550px로 제시한다.
- 300dpi와 6개월 이내 촬영을 권장/요구한다.
- 3.5×4.5cm 인화 기준 머리 길이는 정수리(머리카락을 제외한 머리 최상부)부터 턱까지 3.2~3.6cm다.
- 배경 제거·흰 배경 합성으로 사진이 변형된 경우와 얼굴을 좌우·상하로 납작하게 변형한 경우를 제출 불가 사례로 설명한다.
- 온라인 사진 검증 페이지는 JPG/JPEG 또는 PNG가 가능하다고 별도로 표시한다. 또한 검증은 참고용이며 실제 심사와 다를 수 있고, 검증된 사진도 접수 반려 또는 교부 거부될 수 있다고 명시한다.

구현상 해석:

- 픽셀핏의 생성 기본값은 혼란을 줄이기 위해 413×531px JPEG 하나로 고정한다. 공식 사이트의 업로드 허용 범위 전체를 출력 후보로 노출하지 않는다.
- 500KB는 인코드 뒤 실제 Blob 크기로 검사한다.
- 300dpi를 기록하면 결과를 다시 파싱해 기록 여부를 확인하되 DPI는 픽셀 수와 별개인 메타데이터임을 설명한다.
- 531px 높이에서 3.2~3.6cm는 약 378~425px다. 브라우저 얼굴 bbox가 “머리카락을 제외한 정수리”를 정확히 판별하지 못하므로 이 값은 안내선/휴리스틱이며 자동 승인 판정에 쓰지 않는다.
- 배경 제거·교체, 미화, 비율 변형은 프리셋 allowlist와 실행 게이트에서 금지한다.

자동 검사 한계:

촬영일의 진위, 렌즈 종류, 표정, 눈썹·윤곽 가림, 피부색, 실제 심사 판단은 자동 확정할 수 없다. 얼굴 검출과 머리 길이·배경·밝기·흐림은 참고용 추정이다.

## 2. 주민등록증 사진 3.5×4.5cm

- 기관: 대한민국 행정안전부
- 출처 종류: `official` (물리 크기)
- 확인 출처: [모바일 신분증 — 모바일 주민등록증 발급 안내](https://www.mobileid.go.kr/mip/hps/issuReqstGuidance/issuReqstGuidanceMrc.do)
- 추가 참고 URL: [정부24 주민등록증 재발급 신청](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000018)
- 확인일: 2026-07-22
- 재검증: 필요. 정부24 정상화 뒤 상세 제출 조건을 다시 확인할 것

확인한 규격과 제한:

- 행정안전부 모바일 신분증 페이지는 IC 주민등록증 발급 준비물로 “6개월 이내 촬영된 사진 1장(3.5×4.5cm)”을 표시한다.
- 정부24 URL은 확인 시 주민등록증 민원 상세가 아니라 “정부24 시스템 성능 점검(서비스 중단) 안내”로 리디렉션됐다. 따라서 해당 페이지에서 형식·파일 크기·온라인 픽셀값은 확인하지 못했다.

구현상 해석:

- 공식으로 확인된 값은 물리 크기 3.5×4.5cm다.
- `round(cm / 2.54 × 300)`으로 환산한 413×531px를 픽셀핏의 300dpi 기본 출력으로 사용한다.
- 413×531px를 모든 주민등록증 제출 경로의 공식 온라인 픽셀 규격이라고 표현하지 않는다. 제출처의 별도 파일 조건을 확인하도록 안내한다.
- JPEG/PNG 선택, 원본 비율 크롭, 위치·확대, DPI 기록을 제공할 수 있다. 배경 교체는 공식 보장 기능이 아닌 일반 모드로만 제공하고 제출처 확인 경고를 붙인다.

자동 검사 한계:

실제 촬영 시점, 신청 경로별 추가 규정, 사진 내용의 법적 적합성과 심사 결과를 자동 검증하지 않는다.

## 3. 일반 증명사진 3×4cm

- 기관: 없음
- 출처 종류: `convention`
- 출처 URL: 없음. 사용자 제공 제품 seed의 국내 일반 인화 관행을 사용
- 확인일: 2026-07-22 (seed 채택일)
- 재검증: 특정 제출기관용 프리셋을 추가할 때 해당 기관 출처로 별도 검증

확인/채택한 값:

- 표시 물리 크기 3×4cm
- 300dpi 환산 기본값 `round(3 / 2.54 × 300)` × `round(4 / 2.54 × 300)` = 354×472px

구현상 해석:

- “국내에서 널리 사용되는 일반 인화 규격”으로 표시하고 공식 또는 법정 보편 규격 배지를 사용하지 않는다.
- 원본, 흰색, 연한 회색, 연한 파란색 배경과 여러 크롭 후보를 제공한다.

자동 검사 한계:

제출기관이 다른 물리 크기, 픽셀, 배경색 또는 파일 형식을 요구할 수 있다. 사용자는 해당 기관의 최신 안내를 확인해야 한다.

## 4. YouTube 채널 배너

- 기관: Google LLC / YouTube
- 출처 종류: `official`
- 출처: [YouTube 고객센터 — 채널 브랜딩 관리](https://support.google.com/youtube/answer/10456525?hl=ko)
- 확인일: 2026-07-22
- 재검증: 출시 전 및 분기별 권장

확인한 규격:

- 업로드 최소 크기: 2048×1152px, 16:9
- 최소 크기 기준 텍스트·로고 안전영역: 1235×338px
- 권장 크기: 2560×1440px
- 파일 크기: 6MB 이하
- 보기와 기기에 따라 이미지가 잘릴 수 있음

구현상 해석:

- 출력은 권장 2560×1440px로 만든다.
- 안전영역은 공식 최소 캔버스 좌표 2048×1152에 저장하고 출력 배율 1.25를 적용해 1544×423px로 표시한다. 정수 반올림 정책은 한 유틸리티에서만 적용한다.
- 데스크톱·모바일·TV 오버레이는 공식 안전영역을 이해시키는 “예상 표시”이며 YouTube의 실제 렌더링을 보장하지 않는다.
- 결과 Blob이 6MB 이하인지 재검사한다.

자동 검사 한계:

YouTube의 UI·기기별 크롭은 변경될 수 있고 실제 표시 영역은 계정·기기·제품 업데이트의 영향을 받을 수 있다.

## 5. 파비콘 패키지

- 기관: Google Search Central
- 출처 종류: `official` 참조 + 제품 호환성 결정
- 출처: [Google 검색결과에 표시할 파비콘 정의하기](https://developers.google.com/search/docs/appearance/favicon-in-search?hl=ko)
- 확인일: 2026-07-22
- 문서 표시 최종 업데이트: 2026-02-20 UTC
- 재검증: 출시 전 및 브라우저/플랫폼 패키지 변경 시

확인한 규격과 제한:

- Google 검색 파비콘은 1:1 정사각형이어야 하며 최소 8×8px다.
- 다양한 표시 환경을 위해 48×48px보다 큰 이미지를 권장한다.
- 홈페이지에 파비콘 `link`를 추가하고 크롤링 가능한 안정된 URL을 사용해야 한다.
- 가이드라인을 지켜도 Google 검색결과 노출은 보장되지 않는다.

구현상 해석:

- 16/32/48px PNG, 16/32/48 다중 크기 ICO, 180px Apple touch icon, 192/512px 앱 아이콘, webmanifest와 설치 문서를 한 ZIP으로 제공한다.
- 이 패키지 구성 전체가 Google Search의 공식 의무 규격이라는 뜻은 아니다. 검색 파비콘 공식 기준과 일반 브라우저/PWA 호환성 편의를 결합한 제품 결정이다.
- 래스터 입력을 벡터 변환했다고 표현하지 않는다. 안전한 SVG 정화가 검증되기 전에는 SVG 입력을 지원하지 않는다.

자동 검사 한계:

파일 구조와 이미지 크기는 확인할 수 있으나 각 브라우저, OS 홈 화면, Google 검색의 실제 표시와 시각적 식별성은 보장할 수 없다.

## 6. 사진 개인정보 정리

- 기관: 없음
- 출처 종류: `convention` (제품 개인정보 정책)
- 출처 URL: 없음
- 확인일: 2026-07-22 (정책 채택일)
- 재검증: 지원 포맷·메타데이터 파서 변경 시

구현상 해석:

- JPEG, PNG, WebP 컨테이너에서 사용자가 선택한 개인정보성 EXIF/XMP/IPTC 필드를 제거한다.
- 방향, DPI, ICC, alpha와 압축 픽셀 payload는 가능한 경우 보존 시도하고 실제로 확인된 속성만 보존되었다고 표시한다.
- C2PA, JUMBF, Content Credentials 등 출처 데이터는 제거 대상으로 제공하지 않는다. 파일 수정으로 자격 증명이 유효하지 않게 될 수 있음을 경고한다.
- SynthID 및 출처 표시의 탐지·제거·우회 기능은 범위 밖이다.

자동 검사 한계:

모든 제조사 고유 메타데이터를 식별하거나 모든 출처 자격 증명을 보존한다고 보장할 수 없다. 파서가 인식하지 못한 데이터가 남을 수 있으므로 제거 후 재파싱 결과와 알려진 한계를 함께 표시한다.

## 변경 관리

규격을 바꿀 때는 다음을 한 변경으로 처리한다.

1. 공식 URL을 다시 열고 확인일과 확인 문구를 갱신한다.
2. Registry의 값과 `lastVerifiedAt`을 갱신한다.
3. 스키마·불변식·변환·출력 재검증 테스트를 갱신한다.
4. UI의 출처·확인일·면책을 확인한다.
5. `docs/STATUS.md`에 실제 실행한 검증을 기록한다.
